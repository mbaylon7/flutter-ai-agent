How it works

  • While the AI is fetching: a soft "Looking it up…" line with three dots.
  • When the answer arrives: the bubble appears, with sources listed quietly underneath.
  • Each source is a clickable URL — tap opens it in the browser.
  • If no tools were used, no sources block — just the bubble.
  • If a fetch failed: it's just dropped from the list. No noisy red error.
