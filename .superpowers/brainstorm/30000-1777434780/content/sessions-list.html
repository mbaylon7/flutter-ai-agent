What's on this screen:

  • Top: "Conversations" + + for new chat
  • Search bar (filters titles + previews live)
  • Filter chips: All / Voice / Text / Pinned
  • Pinned section first, then Recent
  • Each row: icon (🎙 voice / 💬 text), title, last preview, time, badges
  • 📌 pin star · long-press a row for rename / delete / pin
  • Bottom: your avatar/name + ⚙ settings

Swipe a row left → quick actions (pin, delete).
Tap a row → goes to home (mic ring) for that session.
Swipe back left → return to current voice screen.
